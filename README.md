# Sistema de Inventario - Negocio

Repositorio para la gestión y control de inventario del negocio, desarrollado como parte de la asignatura de Programación III.

## Descripción
Este proyecto implementa la lógica de control de inventarios, abarcando la gestión de productos, entradas y salidas, diseñado bajo buenas prácticas de control de versiones y colaboración.

## Tecnologías utilizadas
* C# / .NET
* Control de versiones con Git y GitHub
